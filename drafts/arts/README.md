## 実装チェックリスト（[arts.js](../../arts.js) / [base.js](../../base.js)）

1. **パレット変換**：[base.js](../../base.js) の `KEYS`（21色）に色をマッピングする（縁取りは `D` / `ol:'D'` など）。
2. **図形データ化**：[raster.js](../../raster.js) の仕様に合わせて、`0〜100` 座標系の図形配列として [arts.js](../../arts.js) の `ARTS`（必要に応じて `DETAIL`）へ追加する。
3. **盤面サイズ・並び順**：[raster.js](../../raster.js) の `boardSize`（または個別 `w` 指定）と [base.js](../../base.js) の `ORDER` に組み込む。
4. **専用セリフ追加**：[base.js](../../base.js) の `TALK_STAGE` に `hi` / `p` / `c` / `j` / `q` を追加する（`p`・`hi` は吹き出し1行の約16文字以内）。
5. **キャッシュ更新・検証**：[base.js](../../base.js) の `LV_KEY` を更新し、開発モード（`measure.js`）で難易度・勝率を確認する。
